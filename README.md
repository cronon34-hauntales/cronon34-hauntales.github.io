# Hauntales Research Archive

An independent research archive covering folklore, ghost stories, strange historical accounts, mysterious places, and unexplained events.

This project collects notes and references about unusual stories and legends from different parts of the world.

## Topics

* Folklore and mysterious places
* Historical monster sightings
* Ghost legends
* Abandoned places and local mysteries
* Folklore and urban legends

## Website

The archive is published through GitHub Pages.
